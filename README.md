## 📲 Установка

Собирать проект самому не нужно: готовый APK лежит в релизах.

1. Открой страницу [**Releases**](https://github.com/KaiHikkikomori/datamosh_android/releases/latest) и скачай файл `.apk` из блока **Assets** последней версии.
2. Открой скачанный файл на телефоне. Если Android спросит разрешение на установку из неизвестных источников, разреши его для браузера или файлового менеджера, через которые скачал APK.
3. Если Google Play Protect покажет предупреждение, выбери **«Всё равно установить»**. Так бывает с любыми приложениями вне магазина.
4. Запусти **DATAMOSH FM**. На Android 13 и новее разреши уведомления, иначе управление плеером в шторке не появится.

**Требования:** Android 8.0 (API 26) или новее, подключение к интернету.

**Обновление.** Новые версии ставятся поверх старой с сохранением лайков. Если установка поверх не получилась, удали старую версию и поставь новую (лайки при этом сотрутся).

> Хочешь собрать приложение сам? Смотри раздел [Сборка](#-сборка).

## 🧠 Как это работает

```
 AzuraCast (radio.datamosh.ru)
 ├── /listen/datamosh_radio/radio.mp3        ──►  Media3 ExoPlayer  ──►  MediaSessionService
 └── /api/nowplaying/datamosh_radio (JSON)   ──►  RadioRepo (опрос)  ──►  Compose UI + уведомление
```

- **Звук.** MP3-поток 192 kbps играет в `RadioService` (Media3 `MediaSessionService`), поэтому радио не прерывается, когда приложение свёрнуто.
- **Метаданные.** `RadioRepo` опрашивает публичный API AzuraCast. Пока трек играет, запросы идут раз в несколько секунд, ближе к концу трека чаще, чтобы смена отображалась вовремя. Опрос работает только пока открыт экран или запущен сервис.
- **Лайки.** Список хранится в `likes.json`, обложки скачиваются в `covers/` во внутреннюю память приложения. Никаких сторонних баз данных и аккаунтов.
- **Фон.** `1114.webm` скачивается в память приложения при первом запуске. Если загрузка не удалась, видео играет напрямую с сайта.

## 🛠 Сборка

### Что нужно
- [Android Studio](https://developer.android.com/studio) (свежая стабильная версия)
- Интернет при первой синхронизации: Gradle скачает зависимости
- Телефон с Android 8.0 (API 26) или новее

### Шаги
1. Склонируй репозиторий или скачай архив:
   ```bash
   git clone https://github.com/KaiHikkikomori/datamosh_android.git
   ```
2. В Android Studio: **File → Open** и выбери папку проекта (где лежит `settings.gradle.kts`).
3. Дождись **Gradle Sync**. В первый раз это занимает несколько минут.
4. Подключи телефон с включённой отладкой по USB и нажми **Run ▶**, или собери APK:
   **Build → Generate App Bundles or APKs → Generate APKs**.
5. Готовый `app-debug.apk` лежит в `app/build/outputs/apk/debug/`.

> **Про подпись.** Отладочный APK подписывается ключом Android Studio. Чтобы обновления ставились поверх без потери лайков, собирай приложение на одном компьютере или используй собственный ключ: **Build → Generate Signed App Bundle or APK**.

## 🔔 Обновления и выпуск релизов

Приложение берёт данные последнего релиза через GitHub API (репозиторий должен быть публичным) и сравнивает **час** его публикации с часом, зашитым в сборку. Сравнение всегда идёт **по московскому времени**, минуты и секунды не учитываются. Если на GitHub версия свежее, при запуске появится плашка с названием релиза.

Чтобы выпустить обновление:
1. В файле `Updates.kt` поставь в `APP_RELEASE_TIME` дату и час, когда будешь публиковать релиз. Формат `2026-11-26T13:30` означает московское время. Если удобнее указать другой часовой пояс, допиши его, например `2026-11-26T15:30+05:00`, приложение само переведёт время в МСК. Указывай час публикации или чуть позже, но не раньше.
2. Подними `versionCode` и `versionName` в `app/build.gradle.kts` и дату в `BUILD_DATE` (`AppLog.kt`).
3. Собери подписанный APK одним и тем же ключом (**Build → Generate Signed App Bundle or APK**) и проверь его через **Build → Analyze APK…**: в манифесте не должно быть `android:testOnly="true"`, а `versionCode` должен быть новее установленного.
4. Опубликуй релиз на GitHub. **Название релиза пишется как `v1.3`**: именно оно показывается пользователям в плашке «Для приложения вышло обновление v1.3».

Кнопки на плашке: «Установить» открывает страницу релиза, «Напомнить позже» откладывает плашку до конца дня, «Пропустить эту версию» скрывает именно этот релиз (о более свежем напомнит). В настройках есть ручная проверка, которая игнорирует эти отметки.

## 💿 Как обновлять «Ещё от DATAMOSH»

Карточки собраны в одном списке в файле `MoreFromDatamosh.kt`. Чтобы добавить или заменить карточку, положи квадратную обложку в `app/src/main/res/drawable-nodpi/` и добавь строку в список (название, обложка, ссылка). Остальное приложение подстроится само.

## 🐞 Ошибки, логи и отладка

Если что-то работает не так, приложение умеет записывать логи в стандартную папку **Download** на телефоне.

- **Отчёты о крашах** пишутся всегда, автоматически: файл `DATAMOSH_FM_crash_<дата>_<время>.txt` с описанием ошибки, версией приложения и устройством.
- **Подробный лог действий** по умолчанию выключен. Чтобы включить его, открой меню (три точки в левом верхнем углу) и на надписи «Версия приложения» **нажми три раза, затем один раз зажми**. Появится уведомление «Отладка включена». С этого момента при каждом запуске приложения в Download создаётся файл `DATAMOSH_FM_log_<дата>_<время>.txt` с действиями пользователя и событиями внутри приложения (плеер, загрузка треков и обложек, лайки, ошибки сети).
- Чтобы выключить отладку, повтори тот же жест: три нажатия и одно удержание. Появится уведомление «Отладка отключена».

Если сообщаешь о проблеме, прикрепи файл из папки Download. В обратной связи (меню → «Обратная связь») его можно отправить в чат с ботом.

## 🧰 Технологии

- **Kotlin 2.1**, **Jetpack Compose** и Material 3
- **Media3** (`ExoPlayer`, `MediaSession`) для звука и фонового видео
- **Coil** для загрузки обложек
- Стандартный `org.json` и `HttpURLConnection` для работы с API, без лишних библиотек
- Gradle (Kotlin DSL), Android Gradle Plugin 8.9

```
│   ├── AppLog.kt              # отчёты о крашах и журнал действий в папке Download
│   ├── Export.kt              # сохранение текстовых файлов в папку Download

│   ├── PlayerWidget.kt        # виджеты 3×1 и 2×3 для рабочего стола
│   ├── RadioPlayback.kt       # состояние воспроизведения для виджетов
│   ├── Updates.kt             # проверка обновлений через GitHub Releases
│   ├── VideoWallpaperService.kt # живые обои из видео-фона
│   └── Ui.kt                  # весь интерфейс на Compose
└── res/
    ├── drawable-nodpi/        # логотип и картинка иконки
    ├── mipmap-anydpi-v26/     # адаптивная иконка приложения
    ├── layout/widget_player*.xml # разметка виджетов
    ├── xml/                   # описания виджетов, живых обоев и Android Auto
    └── layout/bg_player.xml   # видео-фон (TextureView, обрезка по центру)

```

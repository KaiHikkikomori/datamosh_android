## 📲 Установка

Собирать проект самому не нужно: готовый APK лежит в релизах.

1. Открой страницу [**Releases**](https://github.com/kaihikkikomori/datamosh_android/releases/latest) и скачай файл `.apk` из блока **Assets** последней версии.
2. Открой скачанный файл на телефоне. Если Android спросит разрешение на установку из неизвестных источников, разреши его для браузера или файлового менеджера, через которые скачал APK.
3. Если Google Play Protect покажет предупреждение, выбери **«Всё равно установить»**. Так бывает с любыми приложениями вне магазина.
4. Запусти **DATAMOSH FM**. На Android 13 и новее разреши уведомления, иначе управление плеером в шторке не появится.

**Требования:** Android 8.0 (API 26) или новее, подключение к интернету.

**Обновление.** Новые версии ставятся поверх старой с сохранением лайков. Если установка поверх не получилась, удали старую версию и поставь новую (лайки при этом сотрутся).

> Хочешь собрать приложение сам? Смотри раздел [Сборка](#-сборка).

## 🧠 Как это работает

```
 AzuraCast (radio.datamosh.ru)
 ├── /listen/datamosh_radio/radio.mp3        ──►  Media3 ExoPlayer  ──►  MediaSessionService
 └── /api/nowplaying/datamosh_radio (JSON)   ──►  RadioRepo (опрос)  ──►  Compose UI + уведомление
```

- **Звук.** MP3-поток 192 kbps играет в `RadioService` (Media3 `MediaSessionService`), поэтому радио не прерывается, когда приложение свёрнуто.
- **Метаданные.** `RadioRepo` опрашивает публичный API AzuraCast. Пока трек играет, запросы идут раз в несколько секунд, ближе к концу трека чаще, чтобы смена отображалась вовремя. Опрос работает только пока открыт экран или запущен сервис.
- **Лайки.** Список хранится в `likes.json`, обложки скачиваются в `covers/` во внутреннюю память приложения. Никаких сторонних баз данных и аккаунтов.
- **Фон.** `1114.webm` скачивается в память приложения при первом запуске. Если загрузка не удалась, видео играет напрямую с сайта.

## 🛠 Сборка

### Что нужно
- [Android Studio](https://developer.android.com/studio) (свежая стабильная версия)
- Интернет при первой синхронизации: Gradle скачает зависимости
- Телефон с Android 8.0 (API 26) или новее

### Шаги
1. Склонируй репозиторий или скачай архив:
   ```bash
   git clone https://github.com/kaihikkikomori/datamosh_android.git
   ```
2. В Android Studio: **File → Open** и выбери папку проекта (где лежит `settings.gradle.kts`).
3. Дождись **Gradle Sync**. В первый раз это занимает несколько минут.
4. Подключи телефон с включённой отладкой по USB и нажми **Run ▶**, или собери APK:
   **Build → Generate App Bundles or APKs → Generate APKs**.
5. Готовый `app-debug.apk` лежит в `app/build/outputs/apk/debug/`.

> **Про подпись.** Отладочный APK подписывается ключом Android Studio. Чтобы обновления ставились поверх без потери лайков, собирай приложение на одном компьютере или используй собственный ключ: **Build → Generate Signed App Bundle or APK**.

## 🧰 Технологии

- **Kotlin 2.1**, **Jetpack Compose** и Material 3
- **Media3** (`ExoPlayer`, `MediaSession`) для звука и фонового видео
- **Coil** для загрузки обложек
- Стандартный `org.json` и `HttpURLConnection` для работы с API, без лишних библиотек
- Gradle (Kotlin DSL), Android Gradle Plugin 8.9

## 📁 Структура проекта

```
app/src/main/
├── java/ru/datamosh/radio/
│   ├── MainActivity.kt        # точка входа, запрос разрешения на уведомления
│   ├── RadioService.kt        # фоновое воспроизведение (Media3 MediaSessionService)
│   ├── RadioRepo.kt           # опрос AzuraCast, состояние эфира, история
│   ├── RadioViewModel.kt      # связь UI с плеером, лайки
│   ├── LikesStore.kt          # локальное хранение лайков и обложек
│   ├── Background.kt          # скачивание и кеширование видео-фона
│   ├── RadioApplication.kt    # инициализация хранилища лайков
│   └── Ui.kt                  # весь интерфейс на Compose
└── res/
    ├── drawable-nodpi/        # логотип и картинка иконки
    ├── mipmap-anydpi-v26/     # адаптивная иконка приложения
    └── layout/bg_player.xml   # видео-фон (TextureView, обрезка по центру)

```
